Новости → Telegram-канал
Бот каждые 30 минут собирает свежие новости с Público, Observador и CNN Portugal и публикует их в ваш Telegram-канал: заголовок, пара предложений, фото и название источника (без ссылки). Если подключить Claude API, бот пересказывает новости своими словами на русском или на любом другом языке.
Запуск (≈15 минут)
1. Создайте бота
Откройте в Telegram @BotFather и отправьте `/newbot`.
Придумайте имя. В ответ придёт токен вида `123456:ABC-...`, сохраните его.
Откройте свой канал → Управление каналом → Администраторы → Добавить администратора, найдите бота и дайте ему право публиковать сообщения.
2. Создайте репозиторий на GitHub
Зайдите на github.com → New repository. Подойдёт приватный, например `news-bot`.
Загрузите файлы: `bot.py`, `requirements.txt` и `README.md`.
Файл `news.yml` положите по пути `.github/workflows/news.yml`. Через веб-интерфейс: Add file → Create new file, в поле имени впишите `.github/workflows/news.yml` и вставьте содержимое.
3. Добавьте секреты
Settings → Secrets and variables → Actions → New repository secret:
Имя	Значение
`TELEGRAM_BOT_TOKEN`	токен от BotFather
`TELEGRAM_CHANNEL`	`@имя_канала` (для приватного канала — числовой id вида `-100…`)
`ANTHROPIC_API_KEY`	необязательно. Ключ с console.anthropic.com: с ним бот пересказывает новости, без него публикует оригинальный заголовок и анонс на португальском
4. Запустите
Actions → News to Telegram → Run workflow.
Первый запуск ничего не публикует: бот только запоминает новости, которые уже есть на сайтах, чтобы не завалить канал сотней постов. Начиная со второго запуска (через 30 минут) в канал пойдут только новые новости.
Настройки (необязательно)
Settings → Secrets and variables → Actions → вкладка Variables:
Переменная	Что делает	По умолчанию
`POST_LANGUAGE`	язык пересказа (`русский`, `English`, `português`…)	`русский`
`MAX_POSTS_PER_RUN`	сколько постов максимум за один запуск	`5`
`KEYWORDS`	публиковать только новости с этими словами, через запятую, например `Sintra,turismo,caravana`	всё подряд
`QUIET_START` / `QUIET_END`	тихие часы по времени Лиссабона: в это время бот ничего не публикует	`21:00` / `08:30`
`DIGEST_TIME`	время итогового поста «Главное за день» (`off` — отключить)	`21:00`
Частоту проверок меняет строка `cron` в `news.yml`, например `0 * * * *` — раз в час.
Как это устроено
Только Португалия. Claude проверяет каждую новость и пропускает те, что не касаются Португалии и людей, которые здесь живут. Без ключа Anthropic фильтр не работает и публикуется всё.
#важно. Новости об иммиграции, AIMA, ВНЖ, визах, гражданстве, а также о русских, украинцах и белорусах помечаются тегом `#важно` и публикуются в первую очередь.
Тихие часы. С 21:00 до 08:30 по Лиссабону бот не публикует. Ночные новости ждут утра; из них сохраняются до 10 (сначала важные, затем самые свежие).
Итоги дня. В 21:00 выходит пост «Главное за …» со списком до 10 главных новостей дня. Из-за очереди GitHub Actions он может выйти на 5–20 минут позже.
Público и Observador читаются через RSS. У CNN Portugal публичной ленты нет, поэтому бот берёт ссылки на статьи с главной страницы и читает заголовок, описание и картинку из каждой статьи.
Уже опубликованные ссылки хранятся в `seen.json`, который бот сам сохраняет в репозиторий. Поэтому повторов не будет.
Посты от разных сайтов чередуются, чтобы один источник не занимал всю ленту.
Если что-то не работает
В канал ничего не приходит: проверьте, что бот — администратор канала с правом публикации, и что `TELEGRAM_CHANNEL` указан с `@`.
Ошибки видны во вкладке Actions: откройте последний запуск, в логе по каждому сайту написано, сколько новостей найдено и что отправлено.
Сайт поменял вёрстку (чаще всего это бывает с CNN Portugal): пришлите мне лог, я поправлю шаблон ссылок в `SOURCES` в начале `bot.py`.
